# Task-1-Data-Cleaning-and-Preprocessing
Data Cleaning and Preprocessing using Excel - Medical Appointment No Shows Dataset

## Objective

The objective of this task was to clean and prepare the Medical Appointment No Shows dataset using Microsoft Excel by identifying and resolving common data quality issues.

## Dataset

Medical Appointment No Shows Dataset (Kaggle)

## Tools Used

* Microsoft Excel

## Data Cleaning Steps

* Checked for missing values using Excel filters (no missing values found).
* Checked for duplicate records using Remove Duplicates (no duplicates found).
* Renamed column headers to a clean and consistent format.
* Converted ScheduledDay and AppointmentDay to `dd-mm-yyyy` format.
* Verified that categorical values such as Gender and No-show were consistent.
* Removed the record with an invalid Age value (`-1`).
* Verified numeric columns and overall data quality.

* medical_appointment_raw.csv
* medical_appointment_cleaned.xlsx
* medical_appointment_cleaned.csv

## Outcome

The dataset was cleaned and prepared for further analysis and visualization.
